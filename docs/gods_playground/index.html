ゲームの準備

  1. 領地の価値の印（黒の円柱）を、5つの地方とも3に置く（ボードの黒い点）。英語版ルールブック p.3
  2. お金は1人10（金色＝5・銀色＝1）。最初のスタートプレイヤーはダイスで決める。英語版ルールブック p.3
  3. スタートプレイヤーから時計回りに、空いているいちばん内側の領地にディスクを1つずつ。1周ごとにスタートプレイヤーの印を次の人へ回し、3周する（1人3つ・違う地方でもよい）。英語版ルールブック p.3
  4. ターンの印は1つ目のマス、フェイズの印は「収入」に。コサック2つ・王のキューブと国軍・土地管理人はそれぞれの箱へ。敵のキューブとハプスブルクのコマはボードの横に。英語版ルールブック p.3

1ターンの流れ（フェイズ1〜8 準備・内政）

  1. 収入: 自分の領地ごとに、その地方の領地の価値だけもらう。土地管理人を置いた領地は＋2。合計が少なくても最低10。英語版ルールブック p.3
  2. 貴族ブロック: 5つの地方とポーランド軍の箱に1個ずつ、裏向きで全員同時に。表にして、数字の数だけ自分の貴族キューブを地方へ（手持ち20個まで）。ブロックは使い切りで、第2ターンの終わりに12個戻る。英語版ルールブック p.4・英語版ルールブック p.13
  3. 王の選出: ポーランド軍の箱にいちばん大きい数字を置いた人がスタートプレイヤー。同点はお金を握って競る（払いは勝敗によらず銀行へ）。英語版ルールブック p.4
  4. ポーランド軍: 3人の数字の合計でボード左下の表の兵、ボード下の王の絵の基本の兵を足す。第1ターンは砲兵なし。駒の数が上限（歩兵4・騎兵4・砲兵1）。英語版ルールブック p.4・デザイナーの回答・非公式 FAQ（BGG）
  5. イベント: スタートプレイヤーがダイス4つ。同じ番号の敵の箱に強さのキューブを1つずつ。6は何もなし。5（ハプスブルク）は第3ターンまで影響力のコマ。英語版ルールブック p.5・英語版ルールブック p.9
  6. 選挙: 地方ごとに貴族キューブが単独で最多の人がキューブ1つを外し、議会のその地方の席にディスク。同点なら空席。最多なら断れない。英語版ルールブック p.5
  7. 領地の建設: 順に1つずつ、その地方の空いているいちばん内側にディスク。1周目はキューブ1、2周目からは2。一度パスしたら終わり。英語版ルールブック p.5
  8. 特別行動を2回: 順に1つずつ、2周。同じ行動を2回選んでもよい（外交と都市は全員で1ターンに1つ）。英語版ルールブック p.6

1ターンの流れ（フェイズ9〜16 戦い・決算）

  1. 兵を雇う: 順に1回ずつ、パスするまで。地方のキューブ1つで、その地方に何人でも。敵のキューブがいる地方は半額。兵はターンの終わりに戻る。英語版ルールブック p.7
  2. 遠征: 地方のキューブ1つで、つながった敵の箱を攻める。当たりはまず地方の中の敵を減らし、残りで手元のキューブを敵の箱へ。国軍を連れていくなら議会のディスク1つ。その地方に自分の兵が1つ以上いるときだけ（振る前に決める・当たりは王のキューブ）。パスするまで順に。英語版ルールブック p.8・デザイナーの回答・非公式 FAQ（BGG）・デザイナーの回答（BGG）
  3. 敵の攻撃: ダイス4つで強さを足す。条約の相手の番号が2つ以上なら、その目はキューブを足さずに条約が破れる。第2ターンは6ごとにコサックが寝返る（ウクライナに置いた物から・2つまで）。番号の小さい敵から、強さが箱の貴族と王のキューブの合計より大きければ、差の数が地方へ。その地方の兵は全部が1回ずつ振る。英語版ルールブック p.9
  4. ポーランドの反撃: 国軍だけで地方の敵のキューブを攻める（自分の兵とは組まない・ハプスブルクのコマは攻められない・コサックは入らない・余った当たりは捨てる）。スタートプレイヤーは最初の1回がただ。あとは誰でも（スタートプレイヤーも）ディスク1つで1回ずつ。やめたら終わり。英語版ルールブック p.11・デザイナーの回答・非公式 FAQ（BGG）
  5. 敵の拡大: 地方の敵が全員の貴族キューブより多ければ、同じ色の矢印の先へ差の数をストックから新しく置く。すでにその敵がいる地方へは広がらない。広がった先でも地方の兵が1回ずつ振る。ストックが足りなければ敵の箱から取り、それでも足りなければ広がる先に均等に分ける。英語版ルールブック p.11・デザイナーの回答・非公式 FAQ（BGG）
  6. 領地: 敵のいる地方は「敵−全員の貴族キューブ」個の領地を、円の数字の大きい方から失う（最低1つ）。都市も領地といっしょに失う。価値は、平和なら＋1（このターン新しく敵が入らなかった。前のターンから残った敵を倒しただけも平和）・新しく入った敵を追い返したらそのまま・敵が残ったら−1（1〜5）。英語版ルールブック p.12・デザイナーの回答・非公式 FAQ（BGG）
  7. 得点: 敵の箱ごとにキューブ最多の人が箱の点（同点は分けて端数は捨てる・王が最多なら誰も取らない・王と同点なら王の分は消える）。議会のディスク1つ2点。お金は5ごとに1点にして返す（持ち越しは4まで）。英語版ルールブック p.13
  8. ターン終了: 敵の箱と議会を空にし、兵（コサックも）と国軍を戻し、条約を外す。地方の敵はその地方の貴族キューブと同じ数まで減らして残す（ハプスブルクのコマは減らさない）。貴族キューブは残る。英語版ルールブック p.13・デザイナーの回答・非公式 FAQ（BGG）

特別行動

  1. 土地管理人（キューブ1）: その地方の自分の領地の下に置く。収入＋2（1つの領地に1つ）。英語版ルールブック p.6
  2. ダンツィヒ（プロイセンのキューブ1）: プロイセンの領地の価値の2倍のお金。領地が無くてもよい。英語版ルールブック p.6
  3. 外交（その敵につながる地方のキューブ1・ディスク1・お金はダイス＋2）: その敵と条約（宣言したら取り消せない）。攻めてこないが、その箱へ遠征もできない（地方の敵とは戦える）。条約を結んでも、地方にいるその敵は広がる。全員で1ターンに1つ。オスマンとは不可。ハプスブルクは第4ターンだけ・オスマンがウィーンにいなければ。お金が足りなければ結べない。英語版ルールブック p.6・デザイナーの回答・非公式 FAQ（BGG）・デザイナーの回答（BGG）
  4. キューブの移動（払う物なし）: 自分のキューブ1〜2個を好きな地方へ。英語版ルールブック p.6
  5. 自由拒否権（どこかのキューブ1）: 議会のディスクを全員分取り除く（自分の分も）。英語版ルールブック p.6
  6. イエズス会の学校（第2ターンから）: 地方ごとにキューブ1つとお金2で1点。5つ全部なら＋2で7点。英語版ルールブック p.7
  7. 新しい都市（第3ターンから・全員で1ターンに1つ・キューブ2）: その地方の自分の領地の下に。最後にその領地の点が3倍。英語版ルールブック p.7
  8. 連盟（第3ターンから・単独最下位の人だけ・キューブ2）: その地方で自分よりキューブの少ない人たちの領地のうち、円の数字がいちばん小さい物を自分の物に（キューブは払う前の数で比べる・都市のある領地は不可・土地管理人は外す）。英語版ルールブック p.6・英語版ルールブック p.7

戦いと敵の箱

  1. 当たりの目: 歩兵5以上（2金）・騎兵4以上（4金）・コサック4以上（2金・ウクライナだけ）。歩兵・騎兵・コサックごとにダイス1つ。守りでは、その地方の兵が全部振る。砲兵（6金・第2ターンから）は振らず、自分の兵とコサックの全部の目に＋1（国軍は国軍の砲兵で）。1の目の兵は消える（砲兵がいても）。英語版ルールブック p.7・英語版ルールブック p.8・ボードの印刷
  2. コサックは、ウクライナに自分の歩兵か騎兵がいる人なら誰でも遠征に使える。ポーランドの反撃では使えない。攻められるのはタタールだけ。雇われなかった物と寝返った物はタタールの箱へ（強さ＋1ずつ）。英語版ルールブック p.7・英語版ルールブック p.8・デザイナーの回答・非公式 FAQ（BGG）

ハプスブルクとオスマン

  1. ハプスブルクは第1〜3ターン、兵でなく影響力のコマ。ターンの初めに箱へコマを2・4・6個置く。遠征も条約もできない。英語版ルールブック p.6・英語版ルールブック p.8・英語版ルールブック p.9・デザイナーの回答（BGG）
  2. 敵の攻撃のとき、コマ1つと大ポーランドの貴族キューブ1つが打ち消し合う（スタートプレイヤーから順に1つずつ）。残ったコマが大ポーランドへ。英語版ルールブック p.9
  3. 地方のコマはその数だけ領地を失わせ、価値を−1。大ポーランドは貴族キューブ2つ以上でないと価値が上がらない（オスマンがウィーンにいないとき）。英語版ルールブック p.12
  4. コマは敵の拡大で紫の矢印の先へも広がり、入った先の貴族キューブを打ち消す。ターンの終わりにも減らさず残り、次のターンの敵の攻撃で、その地方の貴族キューブと1対1で打ち消す。国軍では攻められない。どの敵のキューブでも、同じ所に入るとコマはすぐ消える。英語版ルールブック p.10・英語版ルールブック p.11・デザイナーの回答・非公式 FAQ（BGG）
  5. 第3ターン、オスマンは小ポーランドでなくウィーン（ハプスブルクの箱）へ攻め込む。反撃で国軍だけがウィーンを攻められる（第4ターンも）。ウィーンには貴族キューブ2つ分があるとして、それを超える分が大ポーランドへ広がる。英語版ルールブック p.10・英語版ルールブック p.11
  6. 第3ターンの終わりにウィーンのオスマンは2つまで減らして残す。第4ターンはオスマンの箱の強さが10（ボードが正しく、ルールブックの12は誤り）、ウィーンにも10足し、5の目もウィーンへ。ウィーンのオスマンはハプスブルクの代わりに大ポーランドを攻め（ウィーンの2つ分は数えない）、紫の矢印で広がる。デザイナーの書き込み（BGG）・デザイナーの回答・非公式 FAQ（BGG）・デザイナーの回答（BGG）・英語版ルールブック p.5
  7. オスマンがウィーンに残れなかったら、第4ターンはオスマン3・ハプスブルク9（兵で攻める・条約も可）。どちらでも第4ターンはハプスブルクの箱へ遠征できる。デザイナーの書き込み（BGG）・デザイナーの回答（BGG）・英語版ルールブック p.6

間違えやすいところ

  1. 貴族キューブは攻め込まれても取られない（ハプスブルクのコマは別）。英語版ルールブック p.11
  2. 拡大はストックから新しく置く（元の地方の敵は減らない）。英語版ルールブック p.11
  3. 敵のいる地方では、貴族キューブが多くても領地を最低1つ失う。英語版ルールブック p.12
  4. 大ポーランドから小ポーランドへの紺の矢印は、紫（ハプスブルク）の矢印として扱う（ボードの色の誤り）。デザイナーの回答・非公式 FAQ（BGG）
  5. お金は4までしか持ち越せない。英語版ルールブック p.13
