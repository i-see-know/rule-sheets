ゲームの流れ

  1. 旅の床屋になって町を回り、道で薬の材料を集め、町の市場で売り、手紙を届け、弟子を育てる。最後に点がいちばん多い人の勝ち。英語版ルールブック p.2・英語版ルールブック p.7
  2. 4人は8ラウンド（メディクスがはじめの町に戻ってきたラウンドで終わり）。3人は9ラウンド。2人は町のカードの山を使い切るまで（8ラウンド）。英語版ルールブック p.7・英語版ルールブック p.10
  3. 名声はそのまま点にならない。名声の勝負の強さと、同点のときの決め手になる。英語版ルールブック p.10

1ラウンドの流れ

  1. メディクスが動く（2ラウンド目から）: 時計回りに隣の町へ。メディクスの名声＋2。2人なら中立の床屋も動く（下の「2人で遊ぶとき」）。英語版ルールブック p.7・英語版ルールブック p.10
  2. 行き先を選ぶ: 全員同時に、行き先のダイヤルでこっそり選び、伏せておく。いまいる町は選べない。ほかの人と同じ町は選べる。英語版ルールブック p.7
  3. 手番: スタートプレイヤーから時計回りに1人ずつ（下の「手番」）。英語版ルールブック p.7
  4. ラウンドの終わり: 名声の勝負（下）。そのあとスタートプレイヤーのコマを時計回りに渡す。英語版ルールブック p.7・英語版ルールブック p.10

手番

  1. ダイヤルを見せて、行き先を公開する。英語版ルールブック p.7
  2. 床屋を、いまいる町の市場に置く（1ラウンド目は、もう市場にいる）。英語版ルールブック p.7
  3. 真ん中の丸い道を、近いほうの向きに回って行き先へ。英語版ルールブック p.7
  4. サブのアクション: 丸い道の途中では材料を集めるだけ。行き先の町に入る道で、描かれた順に5つ（下）。英語版ルールブック p.8・出版社 Hall Games の回答（BGG）・出版社 Hall Games の回答（BGG）
  5. メインのアクション: 行き先で、ちょうど1つ（下）。床屋はそのマスに置いて次の手番を待つ。英語版ルールブック p.9
  6. 手番の終わり: 取ったフクロウを置く・杖の条件を見る・補充（下）。英語版ルールブック p.9
  7. しなくてもよい: 弟子へ払うのとメインのアクション以外は、すべてしなくてよい。英語版ルールブック p.8

サブのアクション

  1. 材料を集める（丸い道の途中）: 通った材料の置き場から、1種類につき1つまで。置き場は、個人ボードの空いた袋（2つ・1つに1個）か、処方の本の同じ印。英語版ルールブック p.8
  2. 処方の本に2つそろったら処方のできあがり: 同じ材料2つなら名声2、違う材料なら名声1。本は裏返して個人ボードへ（最後の点になる）。英語版ルールブック p.8
  3. 置いた材料は、袋と本の間で動かせない。袋の材料はいつでも山へ戻して袋を空けられる。英語版ルールブック p.8
  4. 市場で売る: 袋の材料を、市場の同じ印の空いたマスへ1つずつ。置く前に空いていたマスの数（1〜3）だけお金をもらう。早く売った人ほど高い。英語版ルールブック p.8
  5. 最後のマスを埋めた人は、材料を山へ戻し、市場のタイルを裏返して自分の物に。1回の売りで売れるのは市場1枚だけ（新しく出た市場には、同じ手番では売れない）。英語版ルールブック p.8・出版社 Hall Games の回答（BGG）
  6. 市場にフクロウ（知識のマーカー）があれば、そこで1つ以上売った人がもらう。英語版ルールブック p.8
  7. 弟子へ払う（必ず）: この手番に1つ以上売ったら、この町にいる自分以外の弟子の持ち主が、山からお金1ずつもらう（何個売っても1人1つ・売った人のお金は減らない）。英語版ルールブック p.8
  8. 手紙を届ける: いちばん上の手紙の大きな紋章の町に着いたら、お金1か名声1。届けた手紙は手元に残し、その町の手紙を1通取って上に重ねる（次の届け先）。その町に手紙が無ければ取れず、それから先は届けられない。英語版ルールブック p.8
  9. 処方の本を買う: お金1で1冊。作りかけの本を置ける枠（2つ）に空きがあるときだけ。英語版ルールブック p.8
  10. メディクスに会う: メディクスがいれば、お金2でフクロウを1つ。置くのは手番の終わり。英語版ルールブック p.8

メインのアクション（ちょうど1つ）

  1. マスはふさがらない。ほかの床屋がいても、4つから選べる。英語版ルールブック p.9・デザイナー Stefan Feld の回答（BGG）・出版社 Hall Games の回答（BGG）
  2. お金をもらう: 山からお金2。英語版ルールブック p.9
  3. 恩恵のカード: この町の山のいちばん上を1枚。カードに書いてなければ、自分の手番中いつでも使える（もらってすぐでも）。使ったら捨てる。何枚持ってもよい。英語版ルールブック p.9
  4. 弟子を育てる: この町の弟子のマスのうち、いちばん安い空きの値段を払い、個人ボードの次の弟子を置く。個人ボードに描かれた名声をもらう。1つの町に自分の弟子は1人まで。英語版ルールブック p.9・出版社 Hall Games の回答（BGG）
  5. 道具を買う: 1つならお金1。ほかの床屋（中立も）かメディクスが同じ町にいれば、お金3で両方の山から1つずつ（同じ山から2つは不可）。個人ボードの上に左から並べ、同じ道具は重ねる。置くたびに描かれたお金や名声のボーナスをもらう。英語版ルールブック p.9

手番の終わり

  1. この手番で取ったフクロウを、個人ボードの能力のマスへ。能力は次の手番から（このラウンドの終わりの名声の勝負には効く）。英語版ルールブック p.9
  2. アスクレピオスの杖: 条件を初めて満たしたら取る。最初の人が金、2番目の人が銀。英語版ルールブック p.9・英語版ルールブック p.12
  3. 補充: 恩恵のカード・道具・処方の本・市場の、空になった置き場にだけ、補充の山から1枚ずつ。山が無くなったら空いたまま。英語版ルールブック p.9・出版社 Hall Games の回答（BGG）

名声の勝負（ラウンドの終わり）

  1. メディクスのいる町から時計回りに、床屋かメディクスが2つ以上いる町で勝負（弟子は数えない）。英語版ルールブック p.10
  2. 名声のいちばん高いコマの勝ち。同じなら、名声トラックで上に重なっている方。マーカーが同じマスに来たら、動いた方をいちばん上に重ねる。英語版ルールブック p.10・出版社 Hall Games の回答（BGG）・出版社 Hall Games の回答（BGG）
  3. 勝った床屋は、この町でもう1つメインのアクション（手番と違う物）。このとき恩恵のカードは使えない。英語版ルールブック p.10・デザイナー Stefan Feld の回答（BGG）
  4. 勝ったコマは（メディクスでも）名声−1。英語版ルールブック p.10
  5. メディクスか中立の床屋が勝ったら、アクションの代わりに、その町の市場にフクロウを1つ置く。次にそこで売った人の物。英語版ルールブック p.10

最終得点

  1. （できた処方の本＋1）×（市場のタイル＋1）。たとえば本3冊と市場2枚なら 4×3＝12点。英語版ルールブック p.10
  2. 町に置いた弟子: 個人ボードのマスに描かれた2〜6点。英語版ルールブック p.10
  3. 手紙: 届けた物もまだ持っている物も、手元の山の全部が1通1点（配達員のフクロウ1つごとに＋1）。英語版ルールブック p.10・英語版ルールブック p.12・デザイナー Stefan Feld の回答（BGG）
  4. 道具: 個人ボードの上の位置で1〜4点。アスクレピオスの杖: 金4点・銀2点。英語版ルールブック p.10
  5. 残ったお金と材料: 合わせて2つで1点。英語版ルールブック p.10
  6. 使わなかった恩恵のカード: 1枚2点（本文に書き漏れがあり、点の例と出版社の回答にある）。英語版ルールブック p.10・出版社 Hall Games の回答（BGG）
  7. 同点なら名声の多い人。名声も同じなら、上に重なっている人。英語版ルールブック p.10

知識のマーカー（フクロウ）の能力

  1. フクロウはどれも同じ形。取ったら個人ボードの能力のマス（10種類）のどれかに置き、置いたマスの能力が手に入る。英語版ルールブック p.3・英語版ルールブック p.12
  2. 値切り: 売るとき、市場のタイルに描かれた材料のアイコンの数（覆われた物も数える）だけお金。英語版ルールブック p.12・個人ボードの文（英語版）
  3. 名医: 処方ができたとき、いつもの名声に加えて、本の星1つなら2点・2つなら3点。英語版ルールブック p.12・個人ボードの文（英語版）
  4. オボロス: 自分の弟子のいる町で売られると、売った材料1つにつきお金1（自分で売ったときも）。英語版ルールブック p.12・個人ボードの文（英語版）
  5. 伝令の報酬: すぐに名声1とお金1。以降、手紙を届けたときは両方もらう。英語版ルールブック p.12・個人ボードの文（英語版）
  6. 万能の職人: 名声の勝負に勝ったら、手番でしなかったメインのアクションを全部。英語版ルールブック p.12・個人ボードの文（英語版）
  7. 特権: 手番の初めに、いまいる町の向かい側に描かれた材料を、空いた袋に置ける。英語版ルールブック p.12・個人ボードの文（英語版）
  8. 退屈: すぐに4点。英語版ルールブック p.12・個人ボードの文（英語版）
  9. 専門家: 最後に、同じ道具を3枚以上集めた種類ごとに5点。英語版ルールブック p.12・個人ボードの文（英語版）
  10. 配達員: 最後に、1つにつき手紙1通が1点増える（複数置ける）。英語版ルールブック p.12・個人ボードの文（英語版）
  11. 追加の袋: 袋が1つ増える。手番中に袋の材料を処方の本へ動かせる（逆は不可）。英語版ルールブック p.12・個人ボードの文（英語版）

アスクレピオスの杖（7つの条件・金4点／銀2点）

  1. 手紙6通 ／ 名声15 ／ フクロウ5つ ／ 違う道具6種類 ／ できた処方の本4冊 ／ 市場のタイル5枚 ／ 5つの町に弟子。英語版ルールブック p.12

  2. 早起き: 手番の初めにいる町で、好きなメインのアクションを1つ。恩恵のカードの文（英語版）
  3. 好条件: 条件が1つ足りなくても、アスクレピオスの杖を1本取れる。恩恵のカードの文（英語版）
  4. 親しい贈り物: 手番の初めの町か行き先で、そこにいるほかのコマ1つにつきお金2。恩恵のカードの文（英語版）
  5. 手癖の悪さ: メインのアクションのあと、市場から材料を好きなだけ取り、2点。恩恵のカードの文（英語版）
  6. 引く手あまた: 市場の印と合わない材料を1つ売れる。英語版ルールブック p.11・恩恵のカードの文（英語版）
  7. 大収穫: 材料を集めるとき、1種類を選んで、置けるだけ取れる。恩恵のカードの文（英語版）
  8. 自由な選択: 近い道でなく、遠い道を回って行き先へ。英語版ルールブック p.11・恩恵のカードの文（英語版）
  9. 現金払い: お金3で、行き先のメインのアクションを1つでなく全部。英語版ルールブック p.11・恩恵のカードの文（英語版）
  10. 居心地のよい滞在: いまの町にとどまる。材料は集めず、代わりに好きな材料を1つ取って、市場に置くところから続ける。英語版ルールブック p.11・恩恵のカードの文（英語版）
  11. 輝かしい功績: すぐに名声2。英語版ルールブック p.11・恩恵のカードの文（英語版）
  12. 個人授業: メディクスのいる町で、お金3でフクロウを2つ（お金2で1つの代わりに）。恩恵のカードの文（英語版）
  13. 特権的な取引: 市場の最後の材料を売ったら、恩恵のカードを山から2枚引く。恩恵のカードの文（英語版）

2人・3人で遊ぶとき

  1. 3人: 9ラウンド。メディクスの町に置く中立の弟子は2つ。英語版ルールブック p.5・英語版ルールブック p.10
  2. 2人: 使わない色の床屋が中立の床屋。準備で町のカードを1枚めくって、中立の床屋と中立の弟子2つをその町へ。名声は2から（メディクスのマーカーの上に重ねる）。使ったカードは戻して7枚を混ぜ直し、中立の床屋の山札にする。はじめのお金は渡さず、2人ともお金3。英語版ルールブック p.5・英語版ルールブック p.6
  3. 2人: 2ラウンド目から、ラウンドの始めに町のカードを1枚めくって中立の床屋をその町へ（いまいる町のカードなら動かない）。名声＋2。英語版ルールブック p.7・デザイナー Stefan Feld の回答（BGG）
  4. 2人: 中立の床屋の町の市場の次の空きマスに、その印の材料を1つ置く。弟子へのお金もふつうどおり。その市場にフクロウがあれば山へ戻す（満杯でなくても）。満杯になったら市場のタイルは箱へ。英語版ルールブック p.7・出版社 Hall Games の回答（BGG）・出版社 Hall Games の回答（BGG）
  5. 2人: 中立の床屋も名声の勝負をする。勝ったら名声−1で、その町の市場にフクロウを1つ。町のカードの最後の1枚をめくったラウンドが最後。英語版ルールブック p.10

間違えやすいところ

  1. 町の恩恵のカード・道具・処方の本・市場は3枚の山。使うのはいちばん上だけ（下を見て選べない）。英語版ルールブック p.4・出版社 Hall Games の回答（BGG）
  2. 弟子の値段は、その町の弟子のマス（英語版の「your Player board」は誤り）。出版社 Hall Games の回答（BGG）
  3. 丸い道の途中では材料を拾うだけ。売る・手紙などは行き先の町に入る道で。出版社 Hall Games の回答（BGG）・出版社 Hall Games の回答（BGG）
  4. 名声の勝負のもう1つのアクションでは、恩恵のカードは使えない。デザイナー Stefan Feld の回答（BGG）
  5. 中立の弟子をどのマスに置くかは、ルールブックに書かれていない（置く町だけ）。英語版ルールブック p.5
